# Pawn Pinch（はさみ将棋 / Hasami Shogi）

ブラウザだけで遊べる、はさみ将棋のCPU対戦ゲームです。1つのHTMLファイルで動き、インストールやサーバーは不要です。スマホにも対応しています。

**遊ぶ:** https://hideyakamikawa-del.github.io/pawn-pinch/

## 特徴

- CPUの強さは10段階（Lv1: ランダムに近い 〜 Lv10: 4秒間の先読み）
- 勝つためのアシスト（取れる手・取られる手の表示、ヒント）
- 取った/取られた駒の演出と、盤外の置き場
- 角取りルールのあり/なし切り替え
- デモ観戦モード（強いCPU同士の対局を眺める）
- 盤面3種（大理石 / 将棋盤 / チェス盤風）、駒の形4種（ポーン / 日本の将棋 / 象棋 / チャンギ）
- 7言語（日・英・中・韓・西・仏・独）

## ルール

9×9の盤、各9枚。駒は飛車のように縦横へ何マスでも動けます。相手の駒を縦または横に自分の駒2枚ではさむと取れます（一列にまとめて取れます）。自分から相手2枚の間に入っても取られません。相手を残り1枚以下にするか、動かせなくすれば勝ちです。

## プログラム構成

外部ライブラリなしの単一ファイル `index.html`。中身は3層に分けています。

| 層 | 役割 |
|---|---|
| ENGINE（`// ==ENGINE==` 〜 `// ==/ENGINE==`） | 盤面・合法手・取り判定・評価・探索。画面に依存しない純粋な関数だけ |
| UI | 描画、入力、アニメーション、アシスト、デモ進行、多言語辞書 |
| 駒・盤面の見た目 | SVGの`<symbol>`とCSS変数。駒の形は`data-pieces`属性で切り替え |

ENGINEをマーカーで区切ってあるので、Node.jsで取り出して画面なしでテストや自己対戦ができます。

## 工夫した点

### 1. CPUの強さの作り方
探索は negamax + αβ法。強さは「読みの深さ」と「わざとミスする確率」の組み合わせで10段階にしています。

- Lv1〜4: 0〜1手読み。ミス確率で弱さを調整
- Lv5〜6: 2手読み
- Lv7〜10: 反復深化＋時間制限（0.8〜4秒）。時間切れでも必ず直前の深さの結果を使える
- 手の並べ替え（多く取れる手を先に読む）でαβの枝刈りを効かせる
- 探索が奇数手で止まったときは、偶数手の結果を優先（自分の手で終わる読みは相手の反撃を見落としやすいため）

### 2. 「勝負がつかない」問題の調査
「同じ動きの繰り返しで終わらないのでは？」という疑問を、実際に測りました。

1. 同形3回で引分、エンジンが繰り返し手にペナルティを付ける、を実装
2. CPU同士の自己対戦で測ると、**同形反復の発生は0件**。原因は繰り返しではなかった
3. 本当の原因は「**要塞**」。壁際に角から一列に並べた駒は、はさむ場所がなく取れない
4. そこで「最後の取りから60手（まだ取りがなければ120手）で駒数判定、同数は引分」のルールを追加
5. 結果: 平均手数がLv5で364→140手、Lv6で400→115手に短縮

### 3. 測り方で間違えないための工夫
強さの比較は運の幅が大きいことが分かりました。同じ強さ同士を24局戦わせても11勝5敗になることがあります。そこで、少数局の勝敗で結論を出さず、同じエンジン同士の対戦（対照実験）を基準にしました。攻めの形への加点は、1手読みのレベル（Lv2〜4）でだけ有効と確認し、そこにだけ入れています。

### 4. デモ観戦モード
強いCPU同士（Lv7〜9相当、考える時間は短め）が対戦します。毎回同じ対局にならないよう、最初の4〜7手だけランダムに指します。その後は読みで指し、160手で打ち切ります。一時停止・次のデモ・速度変更ができます。

### 5. アシスト
「取れる手」を緑✓で示します。「新たに取られる手」だけを橙で示します。すでに取られそうな駒まで警告すると全部の候補が橙になって使えないため、手を指す前後で比較して**新しく脅威になる駒だけ**を数えます。

### 6. 世界向けの作り
- 駒は文字に依存しないSVG（ポーン風）。日本の将棋の駒（歩/と）なども選べる
- 言語はブラウザ設定から自動選択。日本語画面は「はさみ将棋」、他の言語は「Pawn Pinch」＋小さく「Hasami Shogi」

## テスト

- ルール単体テスト11件（ライン取り、まとめ取り、間に入っても安全、角取り、勝敗など）
- 自己対戦によるレベル間の強さ確認、時間上限（Lv9=2.5秒 / Lv10=4秒）の実測

## 既知の限界
