# Pawn Pinch（はさみ将棋 / Hasami Shogi）

ブラウザだけで遊べる、はさみ将棋のCPU対戦ゲームです。1つのHTMLファイルで動き、インストールやサーバーは不要です。スマホにも対応しています。

**遊ぶ:** https://hideyakamikawa-del.github.io/pawn-pinch/

## 特徴

- CPUの強さは10段階（Lv1: ランダムに近い 〜 Lv10: 4秒間の先読み）
- 勝つためのアシスト（取れる手・取られる手の表示、ヒント）
- 取った/取られた駒の演出と、盤外の置き場
- 角取りルールのあり/なし切り替え
- デモ観戦モード（強いCPU同士の対局を眺める）
- 盤面3種（大理石 / 将棋盤 / チェス盤風）、駒の形4種（ポーン / 日本の将棋 / 象棋 / チャンギ）
- 7言語（日・英・中・韓・西・仏・独）

## ルール

9×9の盤、各9枚。駒は飛車のように縦横へ何マスでも動けます。相手の駒を縦または横に自分の駒2枚ではさむと取れます（一列にまとめて取れます）。自分から相手2枚の間に入っても取られません。相手を残り1枚以下にするか、動かせなくすれば勝ちです。

## プログラム構成

外部ライブラリなしの単一ファイル `index.html`。中身は3層に分けています。

| 層 | 役割 |
|---|---|
| ENGINE（`// ==ENGINE==` 〜 `// ==/ENGINE==`） | 盤面・合法手・取り判定・評価・探索。画面に依存しない純粋な関数だけ |
| UI | 描画、入力、アニメーション、アシスト、デモ進行、多言語辞書 |
| 駒・盤面の見た目 | SVGの`<symbol>`とCSS変数。駒の形は`data-pieces`属性で切り替え |

```
index.html          ゲーム本体（ENGINE + UI）
tests/
  load_engine.js        index.html からENGINE部分だけを取り出す（Node.js）
  rules.test.js         ルールの単体テスト11件
  selfplay_stall.js     自己対戦で決着までの手数を測る（停止ルールの効果）
  strength_match.js     レベル同士の強さ比較
```

### データ表現
- 盤面は `Int8Array(81)`（0=空 / 1=人間 / 2=CPU）。マス番号は `row*9+col`
- 手は `from*81+to` の整数1つ。駒数 `cnt[1], cnt[2]` は差分更新（`applyMove` が取った駒の配列を返し、`undoMove` で厳密に戻す）
- 局面の同一判定は「盤面の文字列＋手番」（`posKey`）。出現回数をハッシュに数える

### 探索
- negamax ＋ αβ法。ノード数2048ごとに時間をチェックし、超過したら例外で打ち切る
- 反復深化。時間切れのときは、完了した最後の深さの結果を使う
- 手の並べ替えは「その手で取れる枚数」の降順。反復深化では前回の最善手を先頭に置く
- 探索が奇数手で止まったときは、**偶数手で完了した結果を優先**する。自分の手で読みが終わると、相手の反撃を見落としやすいため
- 置換表と静止探索は入れていません。盤が小さく分岐が60前後あるため、深さ6まで（Lv9〜10）が現実的な上限です

### 評価関数
`評価 = 駒数差 × 100 ＋ Σ(前進度 × 1.0 ＋ 中央寄り × 0.5)（自分−相手） ＋ 攻めの形の加点`
- 攻めの形: 相手の駒の片側に自駒がいて、反対側が空いている（あと1手ではさめる）形を数えて加点（`ATT=6`）
- **Lv2〜4（1手読み）でだけ有効**。2手読み以上では効果が誤差内だったので 0 にしています

### 強さの10段階

| Lv | 読み | 時間 | ミス確率 | 備考 |
|---|---|---|---|---|
| 1 | 0（ランダム） | - | - | |
| 2〜4 | 1手 | - | 0.5 / 0.2 / 0 | 攻めの形の加点あり |
| 5〜6 | 2手 | - | 0.25 / 0 | |
| 7〜8 | 最大4手 | 0.8 / 1.5秒 | 0.05 / 0 | 反復深化 |
| 9〜10 | 最大6手 | 2.5 / 4秒 | 0 | 反復深化 |

ミス確率は、その確率でランダムな合法手を指すというものです（弱いレベルを作る手段）。

## 工夫した点

### 1. 「勝負がつかない」問題の調査
「同じ動きの繰り返しで終わらないのでは？」という疑問を、実際に測りました。

1. 同形3回で引分、エンジンが繰り返し手にペナルティを付ける（初回40、3回目150。勝ち確定の手には付けない）を実装
2. CPU同士の自己対戦で測ると、**同形反復の発生は0件**。原因は繰り返しではなかった
3. 本当の原因は「**要塞**」。壁際に角から一列に並べた駒は、はさむ場所がなく取れない
4. そこで「最後の取りから60手（まだ取りがなければ120手）で駒数判定、同数は引分」のルールを追加
5. 結果: 平均手数がLv5で364→140手、Lv6で400→115手に短縮

再現: `node tests/selfplay_stall.js 12 5,6`（各レベル12局。結果は乱数で変わります）

### 2. 測り方で間違えないための工夫
強さの比較は運の幅が大きいことが分かりました。同じ強さ同士を24局戦わせても11勝5敗になることがあります。そこで、少数局の勝敗で結論を出さず、同じエンジン同士の対戦（対照実験）を基準にしました。

- 同じレベル同士: `node tests/strength_match.js 5 5 24`
- 違うレベル: `node tests/strength_match.js 4 3 24`

### 3. デモ観戦モード
強いCPU同士（Lv7〜9相当、考える時間は短め）が対戦します。毎回同じ対局にならないよう、最初の4〜7手だけランダムに指します。その後は読みで指し、160手で打ち切ります。一時停止・次のデモ・速度変更ができます。

### 4. アシスト
「取れる手」を緑✓で示します。「新たに取られる手」だけを橙で示します。すでに取られそうな駒まで警告すると全部の候補が橙になって使えないため、手を指す前後で比較して**新しく脅威になる駒だけ**を数えます。

### 5. スマホで使える画面
- 取られた駒の置き場とメッセージが、スマホでは画面の外に出ていたので、設定を折りたたみにして盤と一緒に1画面に収めました
- 駒は文字に依存しないSVG。日本の将棋の駒を既定にし、ポーン・象棋・チャンギにも切り替えられます
- 言語はブラウザ設定から自動選択（7言語）。日本語画面は「はさみ将棋」、他の言語は「Pawn Pinch」＋小さく「Hasami Shogi」

## テスト

Node.js だけで動きます（ライブラリ不要）。

```bash
node tests/rules.test.js          # ルールの単体テスト11件
node tests/selfplay_stall.js 12   # 自己対戦で決着までの手数
node tests/strength_match.js 4 3  # レベル同士の対戦
```

- ルールテスト: ライン取り、まとめ取り、間に入っても安全、角取り、盤端ではさめない、直線移動のみ、undoで完全に戻る、など
- 時間制限付きレベル（Lv9=2.5秒 / Lv10=4秒）は、手元の自己対戦で上限を実測しました

## 制作について

このゲームは、AIアシスタント（Claude）と対話しながら作りました。仕様と方針の決定、遊んでの確認、不具合の指摘は人間が行い、実装と計測はAIが行っています。上記の調査結果は、実際に測った数値です。

## 既知の限界

- 翻訳（中・韓・西・仏・独）は自作で、母語話者の確認はまだです。置換表・静止探索は未実装です
- CPUは最強設定でも人間の上級者に勝てる保証はありません
- 実機のスマホでの操作感は未確認の部分があります
